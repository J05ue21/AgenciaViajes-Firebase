# Desafio 2 Desarrollo de Software para Móviles DSM441
## 🧳Mochila y Brujula
### Aplicacion desarrollada en Kotlin para dispositivos Android sobre la gestión (CRUD) de destinos turísticos.
Para el almacenamiento de la data se emplea Firebase Realtime Database, bajo una estructura noSQL (similar a JSON) que facilita el desarrollo de la aplicacion sin consumir tiempo configurando backend para datos. Con un Plan Spark de Firebase, es suficiente para proyectos de prueba o de menor escala.
Igualmente, la consola Firebase cuenta con el soporte para gestionar autenticaciones con correo y contraseña sin mayor complicación.
Todas estas funcionalidades se obtienen simplemente agregando las dependencias o plugin a nuestro proyecto.
